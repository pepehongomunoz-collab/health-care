# NovaMetabolic™ - Health Care Landing Page

> **Plataforma Médica de Alta Precisión y Tratamiento Integral de la Obesidad**  
> Diseñada para transmitir ciencia, salud, innovación, confianza y alta estética visual.

---

## 🌟 Características Principales

- **Diseño Bioluminiscente & Luxury Clinical UI**: Paleta de colores médica de última generación (Teal `#00E5BE`, Cyan `#0EA5E9`, Índigo `#6366F1` y Esmeralda `#10B981`) con paneles en Glassmorphism.
- **Telemetría y Bio-Monitoreo en Vivo**: Tarjeta interactiva con visualización de curva glucémica continua (CGM sensor) y estabilidad metabólica.
- **Calculadora de Salud Metabólica (4 Pasos)**:
  1. Biometría y cálculo de IMC clínico.
  2. Historial de peso y metas de reducción.
  3. Detección de síntomas neuroendocrinos y resistencia a la insulina.
  4. Diagnóstico personalizado con prescripción del protocolo médico adecuado.
- **Pilares Médicos de Innovación**: Agonistas duales GLP-1/GIP, Bioimpedancia médica de 8 electrodos, telemetría continua y reseteo del *set-point* para evitar el efecto rebote.
- **Casos Clínicos & Testimonios con Biomarcadores**: Métricas verificadas de grasa visceral, glucosa, HbA1c y masa muscular.
- **Modal de Agendamiento & Conexión WhatsApp**: Citas presenciales o por telemedicina con validación y confirmación rápida.

## 🚀 Cómo Ejecutar Localmente

No requiere instalación de dependencias pesadas. Puedes abrirlo directamente o correrlo con un servidor local:

### Opción 1: Con Python
```bash
python -m http.server 3000
```
Luego abre `http://localhost:3000` en tu navegador.

### Opción 2: Con Node.js / npx
```bash
npx serve .
```

### Opción 3:
Abre el archivo `index.html` directamente en tu navegador web favorito.
